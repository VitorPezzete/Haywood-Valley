# Haywood Valley

Jogo de fazenda em pixel art isométrico para o Roblox, escrito em roblox-ts.

## Como rodar

Instale as dependências uma vez:

```bash
npm install
aftman install
```

Para trabalhar, deixe dois terminais abertos na raiz do projeto:

```bash
npm run watch   # compila src/ para out/ a cada mudança
npm run serve   # envia out/ ao Roblox Studio pelo Rojo
```

No Roblox Studio, abra o place, abra o painel do Rojo e clique em Connect.
